Prerequisites

  • Graph — a set of nodes (vertices) connected by edges. Example: people and friendships.
  • Undirected edge — travel both ways (A ↔ B). Directed edge — one way only (A → B).
  • Neighbours — all nodes directly connected to a node.
  • Visited set — a list of nodes we have already discovered. It stops us looping forever in a cycle.
  • Frontier — the nodes discovered but not yet processed (they sit in the queue/stack).
  • Queue = FIFO (First In, First Out). Add at the REAR, remove from the FRONT. Like a line at a shop.
  • Stack = LIFO (Last In, First Out). Add and remove at the TOP. Like a pile of plates.
  • Traversal — visiting every reachable node exactly once.

BFS Breadth-First Search

  • Data structure: Queue (FIFO).
  • Idea: Explore in layers. Visit everything 1 step away, then 2 steps away, then 3…
  • Algorithm: enqueue the start → repeat: dequeue a node, mark it visited, enqueue all of its unvisited neighbours.
  • Why it works: because a queue is FIFO, older (closer) nodes are always processed before newer (further) ones.
  • Guarantee: finds the shortest path (fewest edges) in an unweighted graph.
  • Complexity: O(V + E) time, O(V) space.
  • Used for: shortest path, social-network "degrees of separation", web crawling, GPS on unweighted maps.

DFS Depth-First Search

  • Data structure: Stack (LIFO) — or recursion, which uses the call stack.
  • Idea: Go as deep as possible down one branch; when you hit a dead end, backtrack and try the next branch.
  • Algorithm: push the start → repeat: pop a node, mark it visited, push all of its unvisited neighbours.
  • Why it works: because a stack is LIFO, the most recently pushed neighbour is explored first, so we dive deeper.
  • Does NOT guarantee the shortest path.
  • Complexity: O(V + E) time, O(V) space.
  • Used for: cycle detection, topological sorting, maze solving, connected components, backtracking puzzles.
